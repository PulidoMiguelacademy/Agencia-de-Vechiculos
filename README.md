# 🚗 Agencia de Vehículos

> [!IMPORTANT]
> **REGLA OBLIGATORIA PARA COLABORADORES:**
> Todos los **Pull Requests** deben enviarse únicamente hacia la rama **`develop`**.
> **De lo contrario, la solicitud será rechazada.**

---

## 📋 Guía rápida para subir tu Historia de Usuario

1. **Actualiza la rama `develop` antes de empezar:**
   ```bash
   git checkout develop
   git pull origin develop
   ```

2. **Crea tu rama a partir de `develop` con el número de tu historia:**
   ```bash
   git checkout -b feature-HU-XX-nombre-de-tu-historia
   ```

3. **Verifica que el proyecto compile sin errores antes de subir tus cambios.**

4. **Sube tu rama y crea el Pull Request apuntando únicamente a `develop` (NUNCA a `main` ni a ninguna otra rama).**
